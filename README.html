Quick setup (GitHub + Netlify)

  1. Create a GitHub repo and upload this folder.
  2. In Netlify: New site from Git → select repo.
  3. Publish directory: . (root)
  4. Functions directory: netlify/functions (auto via netlify.toml)
  5. Deploy, then open /start.html to generate the master ZIP.
