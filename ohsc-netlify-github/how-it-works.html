How it works

  1. Client completes one intake form.
  2. Netlify Function applies routing rules (dispensing, records type, staff, etc.).
  3. Server generates a ZIP with folders + Inspection Index.
  4. Client downloads instantly (or you can email the link later).
This starter generates a working ZIP with placeholder documents (TXT) so you can demo immediately. You can later swap TXT placeholders with real PDFs/Word templates.
Disclaimer: This platform assists with documentation aligned to OHSC norms & standards. Final inspection outcomes remain at the discretion of the relevant authorities.
